# Ночная миссия: зажги ABCity

Статическая браузерная игра на сопоставление прописных и строчных английских букв. Ребёнок играет роль читателя-детектива и постепенно возвращает свет ночному ABCity.

## Обучающая цель и уровни

Игра тренирует только соответствие `A–Z` ↔ `a–z`; слов, предложений и фонетических заданий в ней нет.

- Easy: 3 движущиеся буквы, 5 правильных пар.
- Medium: 5 движущихся букв, 7 правильных пар.
- Hard: 8 движущихся букв, 10 правильных пар.

Скорость движения одинакова на всех уровнях. В каждом задании правильный ответ встречается ровно один раз, а варианты не повторяются.

## Жизни и ответы

Easy начинается с 3 жизней. Перед следующим уровнем к оставшимся жизням добавляются 3: максимум 6 на Medium и 9 на Hard. Правильный ответ создаёт световой заряд и освещает часть города. Ошибочная буква превращается в светлячка, отнимает ровно одну жизнь, а текущее задание продолжается. При нуле жизней повторяется только текущий уровень; предыдущие уровни остаются пройденными.

Во время Easy зажигаются первые звёзды и окна, во время Medium — дополнительные окна и дорожки, во время Hard — последние огни. Полное освещение доступно только после завершения Hard.

## Запуск и публикация

ES-модулям нужен локальный HTTP-сервер. Из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/games/night-rescue/`. Игра не требует сборки, backend или внешних API и совместима с GitHub Pages.

Прогресс и настройки сохраняются только в ключе `abcity.nightRescue.v1`.

## Замена ассетов

Текущая графика построена локально в HTML/CSS, а звуки синтезируются Web Audio API. Если появятся утверждённые локальные ассеты, положите изображения в `assets/images/`, аудио в `assets/audio/`, сохраните Web Audio как fallback и не добавляйте внешние runtime-ссылки.

## Доступность

Все интерактивные элементы — настоящие кнопки с видимым фокусом и зонами не меньше 44×44 px. Поддерживаются мышь, касание, Tab, Enter/Space и Escape. Сфокусированная буква останавливается. Есть `aria-live`, подписи элементов, системный и ручной режим уменьшенного движения, раздельные настройки музыки и эффектов.

## Чек-лист тестирования

- [ ] Все 26 букв могут быть целью; регистр сопоставляется правильно.
- [ ] Варианты уникальны; их количество — 3/5/8.
- [ ] Требуется 5/7/10 правильных ответов; скорость не меняется.
- [ ] Жизни стартуют с 3, переносятся и ограничены 6/9.
- [ ] Ошибка снимает одну жизнь и не меняет текущее задание.
- [ ] Retry сохраняет завершённые уровни.
- [ ] Полное освещение появляется только после Hard.
- [ ] Continue, сброс с подтверждением и localStorage работают.
- [ ] Музыка, эффекты, клавиатура и уменьшенное движение работают.
- [ ] Раскладки desktop/tablet/mobile не перекрывают управление.
- [ ] В консоли нет ошибок и сломанных путей.
